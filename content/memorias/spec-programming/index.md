Taller sobre Spec-Driven Development, una metodología para construir software con agentes de IA usando la especificación como contrato entre el humano y la máquina. Se vio qué es SDD, por qué y cuándo usarlo, y se probaron las dos herramientas del ecosistema, Spec Kit y cc-sdd, construyendo juntos un proyecto de ejemplo.
